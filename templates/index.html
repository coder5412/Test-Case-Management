How this workspace works

1. Create a project and import Excel test cases. 2. Start a test execution version. 3. Record each result manually. 4. Create linked bugs for failures. 5. Export CSV, print PDF and compare versions.

Note: This manual-first edition does not launch Selenium from the website. Firebase server-side mirror is optional. SQLite remains the primary local database. User accounts are not enabled; keep this website on localhost.
